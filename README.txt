PŘED ZVEŘEJNĚNÍM DOPLŇTE:
1) Odkaz na Facebook stránku v sekci „Zapojte se“.
2) Po založení oficiální ePetice odkaz v hlavním CTA tlačítku a v sekci „Zapojte se“.
3) Až bude doména definitivní, nahraďte URL v sitemap.xml.
4) Vhodné je později založit projektový e-mail (např. info@obchvatprohradec.cz).

NASAZENÍ NA CLOUDFLARE PAGES:
- Rozbalte ZIP.
- Nahrajte obsah do GitHub repozitáře (index.html musí být v kořeni repozitáře).
- Cloudflare Pages > Create project > Connect to Git.
- Framework preset: None.
- Build command: nechte prázdné.
- Build output directory: /
- Po nasazení připojte vlastní doménu.

DŮLEŽITÉ:
Web je záměrně vytvořen jako informační. Vlastní sběr podpisů ani osobních údajů neobsahuje.
